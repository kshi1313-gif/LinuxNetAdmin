# Project

Linux 네트워크 관리 실습의 프로젝트 산출물을 정리하는 디렉토리입니다. 현재 이 폴더에는 별도 코드나 설정 파일 없이 README만 있으며, 이후 실습 보고서, 구성도, 점검 결과, 작업 로그 등을 모으는 위치로 사용할 수 있습니다.

## 정리하면 좋은 내용

| 항목 | 내용 예시 |
| --- | --- |
| 프로젝트 개요 | 실습 목적, 사용한 Linux 배포판, 네트워크 대역, 서버 역할 |
| 서버 구성 | main, server1, server2 같은 호스트별 역할과 IP 정보 |
| 서비스 구성 | DNS, WEB, FTP, SMB, NFS, MAIL 등 구성한 서비스 요약 |
| 자동화 스크립트 | `Script/` 디렉토리의 스크립트를 어떤 작업에 사용했는지 정리 |
| 트러블슈팅 | 설정 중 발생한 오류, 확인 명령, 해결 방법 |

## 문서 작성 예시

```text
1. 실습 목표
2. 네트워크 구성
3. 서비스별 설정 절차
4. 테스트 결과
5. 문제 해결 기록
6. 개선할 점
```

프로젝트 결과물이 늘어나면 이 README에 목차를 추가하고, 세부 문서는 파일별로 분리해 관리하면 됩니다.
