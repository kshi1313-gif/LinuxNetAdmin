# LinuxNetAdmin

Linux 서버와 네트워크 관리 실습 자료를 모아 둔 저장소입니다. `Project` 브랜치에는 스크립트 예제, 서비스별 설정 파일, 프로젝트 정리 공간이 함께 들어 있습니다.

## 디렉토리 구성

| 경로 | 설명 |
| --- | --- |
| `Project/` | 프로젝트 개요, 실습 결과, 보고서 형태의 문서를 정리하는 공간입니다. 현재는 README 중심으로 구조를 잡아 두었습니다. |
| `Script/` | Bash 기반 Linux 관리 자동화 스크립트를 모아 둔 디렉토리입니다. 기본 문법 예제와 심화 관리 스크립트로 나뉩니다. |
| `configuration/` | Linux 서버 운영에 필요한 환경 파일과 서비스별 설정 예시를 정리한 디렉토리입니다. 네트워크, SELinux, 방화벽, DNS, 웹 서버 등으로 구분되어 있습니다. |

## 사용 전 참고

- 스크립트 중 일부는 `root` 권한, `yum`/`dnf`, `systemctl`, `nmcli`, `ftp`, `telnet`, `expect`, `dialog` 같은 명령을 사용합니다.
- 설정 파일은 실습 환경 기준의 예시입니다. 실제 서버에 적용하기 전에 IP, 도메인, 계정, 경로를 반드시 환경에 맞게 수정하세요.
- `configuration/04_DNS/named.conf`처럼 키, IP, 내부 도메인이 포함될 수 있는 파일은 운영 환경 값으로 그대로 공개하지 않는 것이 좋습니다.

## 추천 작업 흐름

1. `configuration/`에서 서비스별 설정 파일의 목적을 확인합니다.
2. `Script/Essential/`에서 Bash 기본 문법과 조건문, 반복문, 입출력 예제를 확인합니다.
3. `Script/Advenced/`에서 사용자 관리, 네트워크 점검, FTP/Telnet 자동화, 웹 서버 실행 스크립트를 실습합니다.
4. 실습 결과와 정리 내용은 `Project/`에 문서화합니다.
