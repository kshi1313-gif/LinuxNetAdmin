# Configuration

Linux 서버 운영과 네트워크 서비스 실습에 필요한 설정 파일과 메모를 서비스별로 정리한 디렉토리입니다.

## 디렉토리 구성

| 경로 | 설명 |
| --- | --- |
| `00_env/` | Bash, Vim, alias, 프롬프트 등 사용자 작업 환경 설정 예시입니다. |
| `00_files/` | `/etc/fstab`처럼 시스템 공통 파일 예시를 보관합니다. |
| `01_NET/` | `/etc/hosts`, `/etc/resolv.conf` 등 기본 네트워크 설정 파일입니다. |
| `02_SELINUX/` | SELinux 동작 모드를 지정하는 `/etc/selinux/config` 예시입니다. |
| `03_FIREWALL/` | firewalld 기본 명령과 rich rule 정리입니다. |
| `04_DNS/` | BIND DNS 서버의 `named.conf`, zone, reverse zone 파일 예시입니다. |
| `DHCP/` | DHCP 서버 설정 정리를 위한 공간입니다. |
| `FTP/` | FTP 서버 설정 정리를 위한 공간입니다. |
| `iSCSI/` | iSCSI target/initiator 설정 정리를 위한 공간입니다. |
| `MAIL/` | 메일 서버 설정 정리를 위한 공간입니다. |
| `MariaDB/` | MariaDB 서버 설정 정리를 위한 공간입니다. |
| `NFS/` | NFS 공유 설정 정리를 위한 공간입니다. |
| `NTP/` | 시간 동기화 서버와 클라이언트 설정 정리를 위한 공간입니다. |
| `SMB/` | Samba 파일 공유 설정 정리를 위한 공간입니다. |
| `SSH/` | SSH 서버와 클라이언트 보안 설정 정리를 위한 공간입니다. |
| `WEB/` | Apache HTTPD 중심의 웹 서버 설정 파일 위치와 항목 정리입니다. |

## 적용 시 주의

- 저장소의 설정 파일은 실습용 샘플입니다. 운영 서버에 복사하기 전에 도메인, IP, 경로, 계정을 수정하세요.
- 설정 변경 전에는 원본 파일을 백업하세요.
- 서비스별 설정을 적용한 뒤에는 문법 검사, 서비스 재시작, 포트 확인, 로그 확인 순서로 검증하는 것이 좋습니다.
