# Script

Linux 서버 관리와 네트워크 실습을 자동화하기 위한 Bash 스크립트 모음입니다. 기본 문법 연습용 예제와 실제 관리 작업에 가까운 심화 스크립트가 분리되어 있습니다.

## 구성

| 경로 | 설명 |
| --- | --- |
| `ipconfig.sh` | Windows의 `ipconfig`처럼 Linux 네트워크 인터페이스 정보를 보기 좋게 출력하는 스크립트입니다. `nmcli`를 사용합니다. |
| `Essential/` | Bash 기본 문법, 조건문, 반복문, 파일 검사, 입출력, 간단한 서비스 제어 예제입니다. |
| `Advenced/` | 사용자 관리, 네트워크 점검, FTP/Telnet 자동화, 웹 서버 실행, 환경 설정 등 운영 관리 실습 스크립트입니다. |

## 실행 방법

```bash
chmod +x script_name.sh
./script_name.sh
```

관리 작업을 수행하는 스크립트는 시스템 파일 수정, 계정 생성/삭제, 서비스 재시작을 포함할 수 있으므로 필요하면 `sudo` 또는 `root` 권한으로 실행해야 합니다.

## 주의

- IP 대역, 사용자명, 비밀번호, 경로가 실습 환경 기준으로 고정된 파일이 있습니다.
- 실제 서버에서 실행하기 전에 스크립트 상단의 변수 값을 먼저 확인하세요.
- `poweroff`, `userdel`, `systemctl`, `firewall-cmd`를 사용하는 스크립트는 실행 결과가 시스템에 바로 반영됩니다.
